# Лабораторная работа № 6 — Строки. Обработка текстовой информации

Дисциплина: **Основы программирования**

Дата: **02.11.2026**

## Цель работы

1. Познакомиться со строками как типом данных в Python и C++.
2. Научиться создавать строки и выполнять базовые операции.
3. Изучить методы строк: поиск, замена, разбиение, форматирование.
4. Освоить срезы строк и регулярные выражения (кратко).
5. Применить полученные знания для обработки текстовой информации.
6. Отработать навыки работы с Git: коммиты, ветвление, push.

## Как запустить

Нужен Python 3.10 и выше. Команды выполняются из папки `Лабы/лаба6`:

```bash
python лаба1.py
python лаба2.py
python лаба3.py
python sr1.py
```
